## Standards

依据 `CONTRIBUTING.md`，确定调用必须具备作用域、导入、包或类型证据。初审发现三项硬违规：Python 函数局部 import 污染模块绑定；接收者重新赋值仍沿用旧类型；Java `Base x = new Sub()` 错误指向 Base 方法。复核补充发现 Python 循环目标重绑定。

上述问题均已修复：每个调用保存当时的绑定快照，局部导入独立处理；赋值、循环、with、except、推导式不沿用旧类型；Java 使用实际构造类型。独立审查者复跑原始探针及关联测试，限定复核范围内无剩余硬违规。

剩余判断建议是 possible Primitive Obsession：native 解析器仍在类型字典中使用 `exact:` 前缀编码绑定状态。可在后续维护中改为显式记录，这不是本次硬违规。

## Spec

依据 [已批准需求](specs/code-function-mind-map.md)。初审发现四项：动态派发误连；把 wrapper 返回值等同于传入的回调；函数摘要不包含前置文档；验证器仅检查 href 存在而未核对正确函数。复核发现 Java 匿名子类构造仍被视为 exact。

上述问题均已修复并由独立审查者复核：Python self/cls、TS typed 参数和 Java 匿名子类动态调用保留诊断；wrapper 参数只登记 callback binding；文档变化使旧 annotation 失效；实际 href、XMind/Canvas 关系端点必须匹配 canonical 函数。限定复核范围内无剩余需求问题。

后续布局补充校验覆盖箭头两种方向、端点正文遮挡及 Windows 字体实测。增量审查又发现一项：竞争的入/出边可能产生逆向重合曲线，使合法输入校验失败；已在生成时比较正反既有路径并回退引用，补充五函数九边回归。细节见 [验收记录](validation.md)。

规范轴：3 项初始硬违规及 1 项关联残留已关闭，仍有 1 项维护建议；需求轴：4 项初始问题、1 项关联残留及 1 项增量布局问题已修复。两轴独立保留，没有合并排序。
